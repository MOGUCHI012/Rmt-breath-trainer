# RMT — 息に、拍を。

管楽器奏者のための**呼吸筋トレーニング（Respiratory Muscle Training）**を、毎日5分だけ続けるためのWebアプリです。
インストール不要。ブラウザで開くだけで動きます。

呼吸の長さを「秒」ではなく**拍（Beats）**で管理しているのが特徴で、BPMを上げれば同じメニューがそのまま短くなります。時間のない日でも「今日はやらない」ではなく「今日は速く」で続けられます。

---

## 特徴

- **4ステップを通しで5分**（BPM 60のとき、ちょうど300拍）
- **拍ベースの進行** — BPMを上げれば3分にも2分にも短縮できる
- **画面を見なくても進行がわかる** — 吸う合図は上がる2音、吐く合図は下がる2音、休憩明けは「3・2・1」
- **呼吸譜（Breath Score）** — セッション全体を拍幅どおりの帯で可視化。再生ヘッダが走る
- **継続日数（ストリーク）** — 炎の中に日数。1日2回やり切ると炎が青くなる**スーパーストリーク**
- **今月のカレンダー** — 起動画面で、今日までの積み上げが一目でわかる
- 完了後に管楽器奏者向けの**TIPSを20種からランダム表示**

## トレーニングメニュー

| Step | 内容 | パターン | セット |
|---|---|---|---|
| 01 | 横隔膜ストレッチ | 4拍 吸う → 8拍 吐く | 5 |
| 02 | 吸気筋トレーニング | 2拍 吸う → 2拍 休む | 10 |
| 03 | 長時間呼気コントロール | 2拍 吸う → 18拍 吐く | 5 |
| 04 | 最大呼気圧・バーストトレーニング | 1拍「フッ！」×20 → 16拍 休憩 | 2 |

各ステップの「準備 / 動作 / ねらい」は、アプリ内の **?** ボタンから確認できます。
通しでの一括実行と、ステップ単体での実行の両方に対応しています。

**所要時間の目安**

| BPM | 所要時間 |
|---|---|
| 60 | 5:00 |
| 80 | 3:45 |
| 100 | 3:00 |
| 132 | 2:16 |

## 使い方

1. `index.html` をブラウザで開く
2. 初回のみ、使用上の注意に同意する
3. 起動画面（炎とカレンダー）を**タップ**すると、BGMとともにホームへ
4. BPMを決めて「通しで始める」、または各ステップの「開始」

トレーニング中は、円が広がったら吸う・縮んだら吐く。円の中の数字は残りの拍数です。
スペースキー（画面下のボタン）で一時停止できます。

## ファイル構成

```
.
├── index.html                 # アプリ本体（HTML / CSS / JS すべて）
├── manifest.json              # ホーム画面追加用の設定（アプリ名・アイコン）
├── I_Can_t_Get_Started.mp3    # BGM（同じ階層に置くこと）
├── icons/
│   ├── apple-touch-icon.png   # iOS ホーム画面（180px）
│   ├── icon-192.png           # Android
│   ├── icon-512.png
│   ├── icon-maskable-512.png  # Android の円形マスク用
│   └── favicon-32.png         # ブラウザのタブ
└── README.md
```

音源のパスを変えたい場合は、`index.html` 内のスクリプト冒頭にある `BGM_URL` を書き換えてください。
音源が見つからない場合、BGMボタンは自動的に非表示になり、アプリはそのまま動作します。

### ホーム画面に追加する

スマートフォンのブラウザで開き、共有メニューから「ホーム画面に追加」を選ぶと、**RMT** という名前でアイコンが並びます。
そこから起動するとアドレスバーのない全画面で立ち上がり、通常のアプリと同じ感覚で使えます。

## 動作環境

モダンブラウザ（Chrome / Safari / Firefox / Edge）。スマートフォン対応。

- メトロノームは **Web Audio API** で生成しており、`AudioContext` の時計を基準にスケジューリングしています（タブが重くても拍がずれません）
- トレーニング中は **Wake Lock API** で画面の消灯を抑止します（非対応環境では無視されます）
- 書体は Google Fonts から読み込みます。オフライン時は端末の代替書体で表示されます

## データの保存について

継続日数・実行回数・BPM以外の設定は、すべて**お使いの端末内（localStorage）にのみ**保存されます。
サーバーへの送信、アカウント登録、外部への共有は一切ありません。ブラウザのデータを消去すると記録も消えます。

**ストリークの記録ルール**

- 1日1回目の完了で連続日数が **+1**
- 同じ日の2回目は日数を増やさず、その日を**スーパーストリーク**として記録（炎が青くなる）
- 3回目以降は記録が変わらない
- 1日空くと連続日数は1からやり直し
